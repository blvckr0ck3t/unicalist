# Unicalist Display

Шрифт заголовков. Прописные кириллицы, цифры и знаки по сетке вордмарка:
стойка — 1 модуль, высота прописной — 7 модулей, ширины 4–6, просвет 1 модуль.
Диагонали и круглые формы набраны лесенкой — тем же приёмом, что углы кнопок,
маркеры, дизеринг и горы на сайте.

## Сборка

```
pip install fonttools brotli
python3 build.py
cp UnicalistDisplay.woff2 ../assets/
```

`glyphs.py` — сами буквы, обычным текстом: `#` — залитая ячейка, `.` — пустая.
Править буквы нужно там, а не в бинарнике.

## Как подключён

`@font-face` в `styles.css`, применён к `h1`, `h2`, `.case h2` и `.fact-n`.
`h3` и кнопки остаются на system-ui: на мелком кегле пиксельная сетка мылится.

Кегли заголовков кратны 7 — тогда модуль попадает в целый пиксель и стойки
не плывут. Отсюда ступени 21 / 28 / 35 / 42 / 49 / 63 / 84, а не `clamp()`.

## Решено

Шрифт принят в работу как есть. Осознанно не делаем:

- **Строчных нет.** Все заголовки на сайте капсом. Если однажды понадобится
  смешанный набор — набор придётся дорисовывать, это известная дыра.
- **Одно начертание.** Ни светлого, ни жирного. Акцент внутри заголовка
  даётся цветом, не весом.
- **Надстрочные знаки** у Й и Ё стоят выше прописной — так и задумано.
  Единственное следствие: межстрочное в многострочных заголовках держим
  не меньше 1.12, иначе знаки полезут в строку выше.
- **Кернинга нет.** В парах вроде «ГА», «ТА», «АУ» на модульной сетке
  образуется дыра. Правится таблицей пар — если решим доводить.
